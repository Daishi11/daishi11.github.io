01 / GAME & SIMULATION COMING TO EARLY ACCESS

Cyan Moon

The Simulation Program

A sandbox where simple rules turn into unexpectedly beautiful results.

Cyan Moon is a visual simulation playground built around procedural growth and pattern generation. Change parameters and watch even small adjustments transform the entire result.

Experiment with colors and gradients, use presets as starting points, or create your own and share them through compact ShareCodes. Draw tools let you interact with a simulation directly.

There are no levels to clear or predefined solutions to find. Explore at your own pace, and save interesting results as transparent PNG images.

03 / FIREFOX EXTENSION AVAILABLE · OPEN SOURCE

YouTube Punch EQ

Make YouTube and YouTube Music sound the way you want—without changing the sound of everything else.

YouTube Punch EQ is a lightweight Firefox extension with an eight-band equalizer, dedicated bass control, preamp, and customizable presets.

Its fast media detection is built for YouTube's page navigation, helping the equalizer reconnect promptly when videos and songs change. All audio processing stays local in your browser.

No account, telemetry, or external audio processing. Install the extension from Mozilla Add-ons or explore the source code on GitHub.

04 / WINDOWS UTILITY EARLY DEVELOPMENT

ShortcutManager

Some tasks deserve a keyboard shortcut, not another trip through menus.

ShortcutManager is an experimental Windows tray utility for managing global hotkeys and launching applications or actions quickly.

The focus is a lightweight workflow that stays out of the way, with practical controls for managing and temporarily suspending shortcuts.

It's still early in development. There is no public release or estimated release date yet—and progress may take a while.
